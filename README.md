# Система управления университетом (Лабораторная работа №1)

Проект представляет собой объектно-ориентированную модель предметной области «Университет», написанную на языке Python. 

## Особенности реализации
* **Архитектура:** Предметная область разделена на 11 независимых классов, каждый из которых вынесен в отдельный файл. Логика управления вынесена в `manager.py`, точка входа — `main.py`.
* **CRUD-операции:** Реализовано создание, чтение, обновление и удаление данных о студентах.
* **Обработка исключений:** Перехват встроенных ошибок и реализация собственных исключений (`UniversityError`, `EntityNotFoundError`).
* **Сериализация:** Поддержка импорта и экспорта структур данных в форматах `JSON` и `XML`.
* **Стандарты:** Код соответствует рекомендациям PEP 8 и содержит строгие аннотации типов.

## Запуск проекта
1. Убедитесь, что установлен Python 3.11 или выше.
2. Откройте проект в PyCharm или другой среде разработки.
3. Запустите файл `main.py`.

## Результат работы программы
При запуске `main.py` программа автоматически выполняет тестовый сценарий: демонстрирует создание, чтение, обновление и удаление объектов, корректный перехват несуществующих сущностей (ошибка 999) и сохраняет текущее состояние базы в файлы `university.json` и `university.xml` в корневой директории проекта.
